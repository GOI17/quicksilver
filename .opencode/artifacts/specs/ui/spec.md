# Spec: Top Bar with Search

**Domain:** ui  
**Change:** top-bar-with-search  
**Version:** 1.0.0

---

## Overview

This specification defines the implementation of a custom top bar (winbar) component for Neovim that provides a clickable search input to open Telescope's file finder.

---

## Requirements

### REQ-001: Top Bar Position
- **Type:** Component
- **Description:** Top bar MUST be positioned at the top of each window using Neovim's native winbar API (`vim.wo.winbar`)
- **Implementation Note:** The bar spans the full window width at the top edge

### REQ-002: Dynamic Visibility Toggle
- **Type:** Feature
- **Description:** User MUST be able to show/hide the top bar via a global setting
- **Setting Name:** `g.topbar_visible`
- **Type:** boolean
- **Default:** `true`
- **Behavior:** Changes take effect immediately without restart

### REQ-003: Search Input Placeholder
- **Type:** Component
- **Description:** Centered placeholder displaying "Search files" text
- **Position:** Center of the winbar (using `%#WinBarSepLeft#%=%#WinBarSepRight#%` centering syntax)
- **Visual:** Rendered as a clickable component that appears as an input field

### REQ-004: Trigger Telescope File Finder
- **Type:** Interaction
- **Description:** On click of the search input, MUST open Telescope file finder
- **Expected Behavior:** Calls the existing telescope file finder picker (`require('telescope.builtin').find_files` or equivalent)
- **Lazy Loading:** MUST work even if telescope plugin is not yet loaded (use lazy.nvim's `load` mechanism)

### REQ-005: Styling - Bar Background
- **Type:** Visual
- **Description:** Winbar background color
- **Color Value:** `#363646`
- **Implementation:** Define highlight group `WinBar` with `guibg=#363646`

### REQ-006: Styling - Input Border
- **Type:** Visual
- **Description:** Search input border color
- **Color Value:** `#16161D`
- **Implementation:** Define highlight group for input element with `guifg=#16161D` or border highlight

### REQ-007: Styling - Input Background
- **Type:** Visual
- **Description:** Search input background color
- **Color Value:** `#1a1a22`
- **Implementation:** Define highlight group for input element with `guibg=#1a1a22`

## Scenarios

### SCN-001: Top Bar Displays on Neovim Launch
- **Given:** Neovim starts with default configuration
- **When:** User opens any buffer or window
- **Then:** Top bar with "Search files" placeholder is visible at the top of the window
- **And:** Bar background color is `#363646`

### SCN-002: Click Opens Telescope File Finder
- **Given:** Top bar is visible with "Search files" placeholder
- **When:** User clicks on the search input in the top bar
- **Then:** Telescope file finder picker opens
- **And:** User can search and select files

### SCN-003: Hide Top Bar via Setting
- **Given:** Top bar is currently visible
- **When:** User sets `:let g:topbar_visible = 0` or `vim.g.topbar_visible = false`
- **Then:** Top bar disappears from all windows immediately
- **And:** Winbar option is cleared (`vim.wo.winbar = nil`)

### SCN-004: Show Top Bar via Setting
- **Given:** Top bar is currently hidden
- **When:** User sets `:let g:topbar_visible = 1` or `vim.g.topbar_visible = true`
- **Then:** Top bar reappears in all windows immediately

### SCN-005: Telescope Lazy Loading
- **Given:** Telescope plugin has not been loaded yet (lazy.nvim has not triggered it)
- **When:** User clicks "Search files" in the top bar
- **Then:** Telescope is loaded (via lazy.nvim or manual require)
- **And:** File finder picker opens normally

## Technical Implementation Notes

- **File Location:** `lua/quicksilver/ui/` (new directory)
- **Module:** `lua/quicksilver/ui/winbar.lua`
- **Setting:** `lua/quicksilver/options.lua` modification for `g.topbar_visible`
- **Entry Point:** Source in `init.lua`

### Winbar Syntax Pattern
```lua
local function get_winbar()
  if vim.g.topbar_visible == false then
    return nil
  end
  return '%#WinBarSepLeft#%=%#WinBarSepRight#%'
end
vim.wo.winbar = get_winbar()
```

### Click Handling
- Use `vim.api.nvim_buf_set_var` with `on_click` callback or Telescope's picker callback
- The clickable component in winbar requires Neovim 0.10+
